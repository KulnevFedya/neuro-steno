# Ограничения решения

## Поддерживаемые условия
Русский (приоритет) и английский, речь 2–4 говорящих, устройство arm64-v8a, ~4 ГБ RAM.

## Известные ограничения
_Заполняется по результатам тестов._

## Что не входит в текущую версию
Потоковая расшифровка в реальном времени, другие языки.

## Риски демонстрации
Длинные записи на слабом устройстве: время обработки, нагрев.

## Дальнейшее развитие
Догрузка моделей из сети (опционально), более крупная LLM.

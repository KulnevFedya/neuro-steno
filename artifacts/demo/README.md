# Материалы демонстрации

- **Видео демонстрации:** _ссылка будет добавлена перед защитой_ <!-- вставить ссылку на видео -->
- Сценарий видео: установка APK → «Импорт аудио» (тестовый диалог) → прогресс в уведомлении, экран
  заблокирован → расшифровка со спикерами и таймкодами → тап по реплике (плеер) → экспорт JSON →
  «Резюме (LLM)» → режим полёта (всё работает без сети).
- Скриншоты: [docs/img/](../../docs/img/)
- Пример экспорта: `eval/out/<имя>.json` после `scripts/run_eval.sh` (формат — в корневом README).
- Логи прогона: `adb logcat -s STENO` (время этапов, язык LID, RTF).

## Сценарий видео
Снято на эмуляторе (Android, arm64, 4 vCPU) с release-APK из Release v1.0, установленного начисто;
вход — `real_ru_3spk.wav` (2:10, 3 спикера, русский).

1. Стартовый экран: язык «Авто», число спикеров «Авто» → «Импортировать файл».
2. Системный выбор файла → `real_ru_3spk.wav`; обработка стартует сразу.
3. Экран обработки: этапы, прогресс, оставшееся время.
4. Расшифровка: 32 реплики, 3 спикера, таймкоды, RTF в подсказке.
5. Тап по реплике — воспроизведение с этого места, подсветка текущей реплики.
6. Тап по «Спикер 1» → переименование (Maria).
7. Меню ⋮ → «Резюме (LLM)» — локальная модель, без сети.
8. Меню ⋮ → «Экспорт JSON» → сохранение `real_ru_3spk.json` через системный диалог.

Логи прогона: `adb logcat -s STENO` (время этапов, язык LID, RTF).
